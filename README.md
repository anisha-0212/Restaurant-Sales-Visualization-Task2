# Restaurant Sales Visualization – Task 2

## Objective

The objective of this task was to analyze restaurant sales data and create a visual dashboard using Tableau.

## Tool Used

* Tableau

## Visualizations Created

* Sales by Category
* Sales Trend Over Time
* Sales by Location
* Top 10 Menu Items
* Order Type Distribution
* Customer Rating vs Order Total

## Key Insights

* Main category generated the highest sales.
* Downtown Manhattan had the highest sales among restaurant locations.
* Fish & Chips was the top-performing menu item.
* Overall sales showed a decreasing trend over time.

## Files Included

* Tableau workbook
* Restaurant sales dataset
* Dashboard screenshot
* Dashboard PDF

## Conclusion

The dashboard provides a visual overview of restaurant sales performance and helps identify important sales trends, top-performing menu items, and locations.
